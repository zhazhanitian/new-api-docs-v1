Generate a complete song from an inspiration prompt or custom lyrics.

`custom` controls **text fields only**. Mismatched text is ignored; weight fields are still validated:

- `custom=false` (default, inspiration): `prompt` is the inspiration description. `title`, `style`, `negative_tags`, `auto_lyrics`, and `persona_id` are ignored.
- `custom=true` (custom): `prompt` is lyrics. Those text fields take effect.
- `style_weight`, `weirdness_constraint`, `audio_weight`, and `vocal_gender` apply in **both** modes and are validated. Out-of-range values return 400; they are not silently dropped.

This model uses `style` for genre tags, not `tags`. Creativity uses `weirdness_constraint`, not `weirdness`.

- Provide either `version` (`v6` / `v6-wild` / `v6-mini`) or `custom_model_id`, not both. `persona_id` cannot be combined with `custom_model_id`.
- `custom=false`: `prompt` is required (≤3000). `custom=true` and not instrumental: `prompt` is required as lyrics (≤5000).
- `max_mode=true` requires `custom=true` and bills at **2×**. `variety: "max"` does not enable Max billing.
- `duration` is custom-mode only, 10–360 seconds.
