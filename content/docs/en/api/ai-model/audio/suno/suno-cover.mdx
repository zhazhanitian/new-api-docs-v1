Cover an existing song in another style. Source: `task_id` + `audio_index`.

Submitted fields are validated even if the current mode does not use them. They are **not** silently ignored.

- `custom=true`: `prompt` / `title` / `tags` / `negative_tags` / `style_weight` / `weirdness` / `audio_weight` / `persona_id` apply.
- `custom=false`: only `gpt_description` (required).
- If `custom` is omitted: `prompt` → custom; else `gpt_description` → inspiration; else `tags`/`title` → custom.
- Sending `tags` is the recommended style-cover path. Use `weirdness` on new requests.

**Usage A (recommended)** — source song + target style:

```json
{
  "model": "suno-cover",
  "task_id": "task_xxx",
  "audio_index": 1,
  "version": "v6",
  "tags": "jazz, slow"
}
```

**Usage B** — inspiration mode, `gpt_description` required:

```json
{
  "model": "suno-cover",
  "task_id": "task_xxx",
  "audio_index": 1,
  "version": "v6",
  "custom": false,
  "gpt_description": "Re-arrange this song as a slow jazz version"
}
```

- `version`: `v6` / `v6-wild` / `v6-mini`, default `v6`. Mutually exclusive with `custom_model_id`.
- `max_mode` requires custom mode and bills at 2×.
