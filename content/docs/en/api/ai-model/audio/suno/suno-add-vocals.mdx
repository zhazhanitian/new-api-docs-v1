---
title: Add Vocals
full: true
---

Add vocals onto an existing accompaniment. The source **must** come from `suno-upload`; a normal generation task cannot be the source.

Submitted fields are validated even if unused by the current mode. `gpt_description` is required when `custom=false`.

- `version`: `v6` / `v6-wild` / `v6-mini`, default `v6`. Mutually exclusive with `custom_model_id`.
- Unsupported: `auto_lyrics`, `persona_id`, `instrumental`, target duration.
- `max_mode` requires custom mode and bills at 2×. Use `weirdness` on new requests.
