Mash up two existing songs. `task_ids` must contain exactly 2 IDs; optional `audio_indexes` is parallel (default 1).

Submitted fields are validated even if unused. `gpt_description` is required when `custom=false`. `prompt` is required when `custom=true` and `instrumental=false`.

- `version`: `v6` / `v6-wild` / `v6-mini`, default `v6`. `custom_model_id` is mutually exclusive with `version` and `persona_id`.
- Target duration is not supported. `max_mode` requires custom mode and bills at 2×.
