Blend audio tracks from two existing tasks into a new song.

`task_ids` must contain **exactly 2** source task IDs; `audio_indexes` corresponds element-wise (1-based, defaults to 1 for each).

The `custom` flag controls which fields take effect; fields in the wrong mode are **silently ignored**. When `custom=true`: `prompt` (lyrics), `title`, `tags`, `negative_tags`, `auto_lyrics`, `style_weight`, `weirdness_constraint`, `audio_weight`, and `persona_id` are active; `gpt_description` is ignored. When `custom=false`: only `gpt_description` is read (**required**; missing it returns 400). `vocal_gender` works in both modes. When `custom` is omitted, the backend infers: has `prompt` → `true`; no `prompt` but has `gpt_description` → `false`; otherwise has `tags`/`title` → `true`.

- `instrumental` defaults to `false`; `version` supports all seven values, defaults to `v5.5`. Invalid values return `400`.
- Once complete, read `audio_url` from `result.music[]`; generation typically takes 30–120 s; poll every 3–5 s.
