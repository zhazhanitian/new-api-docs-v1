title: Sample to Song
full: true
---

Generate a song from an uploaded sample. The source **must** come from `suno-upload`. `start_s` and `end_s` are required and are not auto-filled.

Submitted fields are validated even if unused. `gpt_description` is required when `custom=false`.

- `version`: `v6` / `v6-wild` / `v6-mini`, default `v6`. Mutually exclusive with `custom_model_id`.
- Target duration is not supported. `max_mode` requires custom mode and bills at 2×.
