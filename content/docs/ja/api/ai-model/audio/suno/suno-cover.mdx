---
title: カバー生成
full: true
---

既存の楽曲を別スタイルでカバーします。ソースは `task_id` + `audio_index`。

送信したフィールドは、現在のモードで使われなくても検証されます。黙って無視されません。

- `custom=true`: `prompt` / `title` / `tags` / `negative_tags` / `style_weight` / `weirdness` / `audio_weight` / `persona_id` が有効。
- `custom=false`: `gpt_description` のみ（必須）。
- `custom` 未指定時: `prompt` あり→カスタム、`gpt_description` あり→インスピレーション、それ以外で `tags`/`title` あり→カスタム。
- `tags` を渡すのが推奨です。新規リクエストは `weirdness` を使います。

**使い方 A（推奨）**

```json
{
  "model": "suno-cover",
  "task_id": "task_xxx",
  "audio_index": 1,
  "version": "v6",
  "tags": "jazz, slow"
}
```

**使い方 B** — `gpt_description` 必須:

```json
{
  "model": "suno-cover",
  "task_id": "task_xxx",
  "audio_index": 1,
  "version": "v6",
  "custom": false,
  "gpt_description": "この曲をスローなジャズ風にカバーして"
}
```

- `version`: `v6` / `v6-wild` / `v6-mini`、デフォルト `v6`。`custom_model_id` と互斥。
- `max_mode` はカスタムモード必須、通常価格の 2 倍。
