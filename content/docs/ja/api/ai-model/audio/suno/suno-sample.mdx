title: サンプルから楽曲生成
full: true
---

アップロードしたサンプルから楽曲を生成します。ソースは **`suno-upload` のみ**。`start_s` と `end_s` は必須で、自動補完されません。

送信したフィールドは使われなくても検証されます。`custom=false` のとき `gpt_description` は必須です。

- `version`: `v6` / `v6-wild` / `v6-mini`、デフォルト `v6`。`custom_model_id` と互斥。
- 目標尺は非対応。`max_mode` はカスタムモード必須、通常価格の 2 倍。
