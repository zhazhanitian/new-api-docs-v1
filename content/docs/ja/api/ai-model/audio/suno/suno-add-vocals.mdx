---
title: ボーカル追加
full: true
---

既存の伴奏にボーカルを追加します。ソースは **`suno-upload` のアップロード音源のみ**。通常の生成タスクは使えません。

送信したフィールドは、現在のモードで使われなくても検証されます。`custom=false` のとき `gpt_description` は必須です。

- `version`: `v6` / `v6-wild` / `v6-mini`、デフォルト `v6`。`custom_model_id` と互斥。
- 非対応: `auto_lyrics`、`persona_id`、`instrumental`、目標尺。
- `max_mode` はカスタムモード必須、通常価格の 2 倍。新規は `weirdness` を使います。
