title: 音楽生成
full: true
---

インスピレーション説明またはカスタム歌詞から完全な楽曲を生成します。

`custom` が決めるのは**テキストフィールド**だけです。モード不一致のテキストは無視されますが、重みフィールドは検証されます。

- `custom=false`（デフォルト、インスピレーション）: `prompt` は説明文。`title`、`style`、`negative_tags`、`auto_lyrics`、`persona_id` は無効。
- `custom=true`（カスタム）: `prompt` は歌詞。上記テキストフィールドが有効。
- `style_weight`、`weirdness_constraint`、`audio_weight`、`vocal_gender` は**両モードで検証・適用**。範囲外は 400 で、黙って捨てられません。

スタイルタグは他モデルの `tags` ではなく `style`。創意度は `weirdness` ではなく `weirdness_constraint`。

- `version`（`v6` / `v6-wild` / `v6-mini`）と `custom_model_id` はどちらか一方必須、同時指定不可。
- `custom=false` では `prompt` 必須（≤3000）。`custom=true` かつ非インストゥルメンタルでは歌詞 `prompt` 必須（≤5000）。
- `max_mode=true` は `custom=true` が必要で、通常価格の **2 倍**。`variety: "max"` では Max 課金になりません。
