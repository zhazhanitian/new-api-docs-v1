2つの既存タスクの音源をミックスして新しい楽曲を生成します。

`task_ids` は**ちょうど2つ**のタスク ID が必要です。`audio_indexes` は対応する順（1始まり、デフォルト1）で指定します。

`custom` フラグにより有効なフィールドが決まります。誤ったモードのフィールドは**無視されます**（エラーなし）。`custom=true` 時: `prompt`（歌詞）、`title`、`tags`、`negative_tags`、`auto_lyrics`、`style_weight`、`weirdness_constraint`、`audio_weight`、`persona_id` が有効、`gpt_description` は無視。`custom=false` 時: `gpt_description` のみ有効（**必須**、未指定は 400）。`vocal_gender` は両モードで有効。`custom` 未指定時は `prompt` あり → `true`、`gpt_description` あり → `false`、`tags`/`title` あり → `true` の順で推定します。

- `version` は全7種対応、デフォルト `v5.5`、無効値は 400。完了後は `result.music[]` の `audio_url` を参照。通常 30〜120 秒。
