2 つの既存楽曲をミックスします。`task_ids` はちょうど 2 件。任意の `audio_indexes` は同順（デフォルト 1）。

送信したフィールドは使われなくても検証されます。`custom=false` のとき `gpt_description` は必須。`custom=true` かつ `instrumental=false` のとき `prompt` は必須です。

- `version`: `v6` / `v6-wild` / `v6-mini`、デフォルト `v6`。`custom_model_id` は `version`・`persona_id` と互斥。
- 目標尺は非対応。`max_mode` はカスタムモード必須、通常価格の 2 倍。
