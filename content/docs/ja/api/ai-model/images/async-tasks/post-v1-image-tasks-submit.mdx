画像生成タスクを送信してタスク ID を取得します。GET エンドポイントでステータスと結果をポーリングしてください。

生成時間が長いモデル（通常 30 秒以上）に推奨されます。

**対応モデル：** `OG-image-2`、`OG-image-2.5-flare`、`OG-image-2.5-sunburst`、`OG-image-2.6-flare`、`OG-image-2.6-sunburst`

**参照画像（Image-to-Image）：** `image`（単一の URL/Base64）または `images`（URL/Base64 の配列）フィールドで参照画像を指定すると、Image-to-Image モードが有効になります。`input_reference` は `image` のエイリアスです。
