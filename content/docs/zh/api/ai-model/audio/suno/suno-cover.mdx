title: 风格翻唱
full: true
---

以另一种风格翻唱已有歌曲。源用 `task_id` + `audio_index`。

已提交字段无论当前模式是否生效，都须通过类型、范围和长度校验，**不是静默忽略**。

- `custom=true`：`prompt` / `title` / `tags` / `negative_tags` / `style_weight` / `weirdness` / `audio_weight` / `persona_id` 生效。
- `custom=false`：只认 `gpt_description`（必填，缺了 400）。
- 不传 `custom` 时：有 `prompt`→自定义；无 `prompt` 但有 `gpt_description`→灵感；否则有 `tags`/`title`→自定义。
- 给 `tags` 即可按自定义风格翻唱（推荐）。新请求用 `weirdness`。

**用法 A（推荐）** — 源歌曲 + 目标风格：

```json
{
  "model": "suno-cover",
  "task_id": "task_xxx",
  "audio_index": 1,
  "version": "v6",
  "tags": "jazz, slow"
}
```

**用法 B** — 灵感模式，必须给 `gpt_description`：

```json
{
  "model": "suno-cover",
  "task_id": "task_xxx",
  "audio_index": 1,
  "version": "v6",
  "custom": false,
  "gpt_description": "把这首歌翻唱成慢速爵士风格"
}
```

- `version`：`v6` / `v6-wild` / `v6-mini`，默认 `v6`；与 `custom_model_id` 互斥。
- `max_mode` 要求自定义模式，2 倍计费。`duration_s` 仅自定义。
- **提交接口**：`POST /v1/music/generations`，`model: "suno-cover"`。
- **任务查询**：`GET /v1/music/generations/{task_id}`。
