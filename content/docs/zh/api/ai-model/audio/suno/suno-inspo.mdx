title: 灵感生成
full: true
---

用 1–4 段公网音频作为灵感参考生成新歌。直接给 `audio_urls`，不走 `task_id`。

- `version`：`v6` / `v6-wild` / `v6-mini`，默认 `v6`；与 `custom_model_id` 互斥。
- 不要发送 `custom`、`instrumental`、`gpt_description`、`persona_id` 或目标时长。
- 创意度字段为 `weirdness`。`max_mode=true` 按 2 倍计费；`variety: "max"` 不会开启 Max。
- **提交接口**：`POST /v1/music/generations`，`model: "suno-inspo"`。
- **任务查询**：`GET /v1/music/generations/{task_id}`。
