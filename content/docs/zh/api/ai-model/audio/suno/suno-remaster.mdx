---
title: 母带优化
full: true
---

对已生成歌曲做母带优化。无版本参数，不要传 `version`。

- 源：`task_id` 必填 + `audio_index`（默认 1）。
- 不支持 `custom_model_id`、`max_mode`、`variety` 或目标时长。
- `variation_category`：`subtle` / `normal` / `high`。
- **提交接口**：`POST /v1/music/generations`，`model: "suno-remaster"`。
- **任务查询**：`GET /v1/music/generations/{task_id}`。
