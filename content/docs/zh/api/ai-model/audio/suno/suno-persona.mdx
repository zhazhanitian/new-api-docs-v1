- 基于已有歌曲直接创建可复用的歌手 Persona。

- 本模型无版本维度，不要传 `version`；即使传入也会被 MAPI 丢弃，不影响计费。
- 使用产出源音轨的 `task_id` 和 `audio_index` 引用歌曲；`name` 为必填字段。
- 新流程无需先提取 Vox，不要传 `vox_audio_id`。对外字段仍用 `description`（平台会转成上游 `describe`）。
- 完成后读取 `result.persona_id`。Persona ID 与自定义模型 ID 不同，不能作为 `model` 或 `custom_model_id` 使用。

- **提交接口**：统一通过 `POST /v1/music/generations` 提交，使用 `model: "suno-persona"` 选择此能力。
- **任务查询**：提交返回 `task_id`，通过 `GET /v1/music/generations/{task_id}` 获取任务状态和结果。
