---
title: 生成混搭
full: true
---

把两首已有歌曲混搭再创作。`task_ids` 须恰好 2 个；可选 `audio_indexes` 与之平行（默认都取 1）。

已提交字段无论模式是否生效都须通过校验。`custom=false` 时 `gpt_description` 必填；`custom=true && instrumental=false` 时 `prompt` 必填。

- `version`：`v6` / `v6-wild` / `v6-mini`，默认 `v6`。`custom_model_id` 与 `version`、`persona_id` 互斥。
- 不支持目标时长。`max_mode` 要求自定义模式，2 倍计费。新请求用 `weirdness`。
- **提交接口**：`POST /v1/music/generations`，`model: "suno-mashup"`。
- **任务查询**：`GET /v1/music/generations/{task_id}`。
