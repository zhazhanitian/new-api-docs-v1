---
title: 生成混搭
full: true
---

把两首已有歌曲混搭再创作。`task_ids` 须恰好 2 个；可选 `audio_indexes` 与之平行（1-based，默认都取 1）。

`custom` 决定哪些字段生效。已提交字段无论当前模式是否生效，都须满足类型、范围和长度。不传 `custom` 时按此推断：有 `prompt` → `true`；无 `prompt` 但有 `gpt_description` → `false`；否则有 `tags` 或 `title` → `true`。

- `custom=true` 时 `prompt`、`title`、`tags`、`negative_tags`、`auto_lyrics`、`style_weight`、`weirdness`、`audio_weight`、`persona_id` 生效，`gpt_description` 被忽略。`custom=true` 且 `instrumental=false` 时 `prompt` 必填。
- `custom=false` 时只读 `gpt_description`（必填，缺失提交期 400、不扣费）。`vocal_gender` 两种模式都生效。
- `version`：`v6` / `v6-wild` / `v6-mini`，省略默认 `v6`。使用 `custom_model_id` 时省略。`custom_model_id` 与 `version`、`persona_id` 互斥。
- 不支持目标时长。`max_mode` 启用要求自定义模式，按普通售价的 2 倍计费。创意度用 `weirdness`，兼容旧名 `weirdness_constraint`。
- **提交接口**：`POST /v1/music/generations`，`model: "suno-mashup"`。
- **任务查询**：`GET /v1/music/generations/{task_id}`。
