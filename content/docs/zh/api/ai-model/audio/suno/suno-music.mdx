---
title: 生成音乐
full: true
---

根据灵感描述或自定义歌词生成完整歌曲。

`custom` 只决定**文本字段**是否生效，不是「写错模式就静默忽略、不报错」：

- `custom=false`（默认，灵感）：`prompt` 作灵感描述；`title`、`style`、`negative_tags`、`auto_lyrics`、`persona_id` 不生效。
- `custom=true`（自定义）：`prompt` 作歌词；上述文本字段生效。
- `style_weight`、`weirdness_constraint`、`audio_weight`、`vocal_gender` **两种模式都会校验并生效**。越界直接 400，不会静默丢掉。

本模型用 `style` 表示风格标签，不是其他模型的 `tags`。创意度字段是 `weirdness_constraint`，不是 `weirdness`。

- `version`（`v6` / `v6-wild` / `v6-mini`）与 `custom_model_id` **至少提供一个，不能同时发送**。只用自定义模型时不要传 `version`。`persona_id` 与 `custom_model_id` 互斥。
- `custom=false` 时 `prompt` 必填（≤3000）；`custom=true` 且 `instrumental=false` 时 `prompt` 必填（歌词 ≤5000）；自定义纯音乐可省略歌词。
- `max_mode=true` 要求 `custom=true`，按普通售价 **2 倍**计费。`variety: "max"` 不会触发 Max 计费。
- `duration` 仅 `custom=true`，范围 10–360 秒。实际成品时长以任务结果为准。
- **提交接口**：`POST /v1/music/generations`，`model: "suno-music"`。
- **任务查询**：`GET /v1/music/generations/{task_id}`。完成后从 `result.music[]` 取 `audio_url`。
