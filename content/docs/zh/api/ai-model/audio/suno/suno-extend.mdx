---
title: 续写延长
full: true
---

在已有歌曲的某个时间点之后续写延长。源用 `task_id` + `audio_index`（默认 1）。

- `continue_at` 必填，必须 ≥1 且小于源音轨实际时长，支持小数秒。
- `version`：`v6` / `v6-wild` / `v6-mini`，省略默认 `v6`；与 `custom_model_id` 互斥。
- `custom` 省略默认 `true`（按 `prompt` 歌词续写）；只有显式 `custom=false` 时才用 `gpt_description`。
- `max_mode` 启用时要求 `custom=true`，2 倍计费。`duration_s` 仅 `custom=true`。新请求用 `weirdness`。
- **提交接口**：`POST /v1/music/generations`，`model: "suno-extend"`。
- **任务查询**：`GET /v1/music/generations/{task_id}`。
