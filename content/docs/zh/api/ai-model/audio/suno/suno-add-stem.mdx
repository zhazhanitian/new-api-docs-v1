---
title: 添加音轨
full: true
---

在现有音轨上叠加一条 stem。用产出源音轨那次任务的 `task_id` + `audio_index` 引用源。

已提交字段无论模式是否生效都须通过校验。`custom=false` 时 `gpt_description` 必填。不支持 `vocal_gender`。

- `version`：`v6` / `v6-wild` / `v6-mini`，默认 `v6`；与 `custom_model_id` 互斥。
- 不支持 `auto_lyrics`、`persona_id`、`instrumental`、目标时长。
- `max_mode` 要求自定义模式，2 倍计费。新请求用 `weirdness`。
- **提交接口**：`POST /v1/music/generations`，`model: "suno-add-stem"`。
- **任务查询**：`GET /v1/music/generations/{task_id}`。
