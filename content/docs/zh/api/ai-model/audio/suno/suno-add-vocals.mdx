---
title: 添加人声
full: true
---

给现有伴奏 / 音轨叠加人声。源必须来自 `suno-upload`，普通生成任务不能作源。

已提交字段无论模式是否生效都须通过校验，不是静默忽略。`custom=false` 时 `gpt_description` 必填。

- `version`：`v6` / `v6-wild` / `v6-mini`，默认 `v6`；与 `custom_model_id` 互斥。
- 不支持 `auto_lyrics`、`persona_id`、`instrumental`、目标时长。
- `max_mode` 要求自定义模式，2 倍计费。新请求用 `weirdness`。
- **提交接口**：`POST /v1/music/generations`，`model: "suno-add-vocals"`。
- **任务查询**：`GET /v1/music/generations/{task_id}`。
