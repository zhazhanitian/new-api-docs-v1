title: 样本转歌曲
full: true
---

以上传样本为基础生成歌曲。源必须来自 `suno-upload`。`start_s`、`end_s` 必填，不会自动补成 0 或 60。

已提交字段无论模式是否生效都须通过校验。`custom=false` 时 `gpt_description` 必填。

- `version`：`v6` / `v6-wild` / `v6-mini`，默认 `v6`；与 `custom_model_id` 互斥。
- 不支持目标时长。`max_mode` 要求自定义模式，2 倍计费。新请求用 `weirdness`。
- **提交接口**：`POST /v1/music/generations`，`model: "suno-sample"`。
- **任务查询**：`GET /v1/music/generations/{task_id}`。
