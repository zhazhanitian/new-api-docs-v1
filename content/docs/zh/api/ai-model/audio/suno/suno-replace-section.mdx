---
title: 段落替换
full: true
---

替换歌曲的某一段（infill）。`start_s`、`end_s` 必填，须满足 `0 ≤ start_s < end_s`。

- `prompt` 是原歌词上下文，`infill_lyrics` 是替换片段的新歌词。
- `version`：`v6` / `v6-wild` / `v6-mini`，默认 `v6`；与 `custom_model_id` 互斥。
- 不要发送 `custom`、`instrumental`、`auto_lyrics` 或旧编辑会话字段。
- `max_mode=true` 按 2 倍计费。
- **提交接口**：`POST /v1/music/generations`，`model: "suno-replace-section"`。
- **任务查询**：`GET /v1/music/generations/{task_id}`。
