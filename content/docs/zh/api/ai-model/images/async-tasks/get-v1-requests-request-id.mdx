通过 `request_id` 查询一次生图请求的扣费金额。

**`request_id` 来源**：调用 `POST /v1/images/generations` 或 `POST /v2/image-tasks` 后，从响应头 `X-Oneapi-Request-Id` 获取。

> 账单记录在请求完成后异步落库，建议延迟 1–2 秒再调用本接口，避免记录尚未写入。

> 异步任务的差额结算和失败退款不会回写这条记录。任务最终扣费以查询异步图像生成任务返回的 `amount` 为准。
