通过任务 ID 查询图像生成任务的当前状态和结果。

建议轮询间隔：3–5 秒。任务通常在 10–90 秒内完成。

任务完成后（`status=SUCCESS`），`images[]` 字段返回所有生成图片的 URL 或 Base64 数据，支持多张（n>1 时多项）。
