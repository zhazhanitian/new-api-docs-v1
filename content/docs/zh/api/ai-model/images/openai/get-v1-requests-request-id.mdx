通过 `request_id` 查询一次同步生图请求（`/v1/images/generations`）的实际扣费金额。

**`request_id` 来源**：调用同步生图接口后，从响应头 `X-Oneapi-Request-Id` 获取。

> 账单记录在请求完成后异步落库，建议延迟 1–2 秒再调用本接口，避免记录尚未写入。
