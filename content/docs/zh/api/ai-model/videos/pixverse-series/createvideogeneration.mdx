提交 PixVerse 视频生成任务（文生、首帧、参考图、多主体参考）。

请求地址仍为 `POST /v1/video/generations`，完成后用 `GET /v1/video/generations/{task_id}` 查询。

素材只通过 `metadata.content` 传入。首帧必须写 `role=first_frame`；不写 `role` 时按参考图提交。不支持尾帧和参考视频。

分辨率使用小写：`540p`、`720p`、`1080p`、`2k`、`4k`，默认 `720p`。

`pixverse-video-c1` 的主体和背景要写 `reference_type` 与 `name`，提示词里用 `@名字` 引用。

各版本能力与字段说明见下方接口文档。
