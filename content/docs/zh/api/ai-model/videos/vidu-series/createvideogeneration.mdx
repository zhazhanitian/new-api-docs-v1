提交 Vidu 视频生成任务（文生、首帧、首尾帧、参考图、参考视频）。

请求地址仍为 `POST /v1/video/generations`，完成后用 `GET /v1/video/generations/{task_id}` 查询。

素材只通过 `metadata.content` 传入。首帧必须写 `role=first_frame`；不写 `role` 时按参考图提交。

尾帧只支持 `vidu-video-q2-pro` 和 `vidu-video-q2-turbo`。参考视频只支持 `vidu-video-q2-pro`。宽高比 `4:3`、`3:4` 只支持 `vidu-video-q2`。

各版本能力与字段说明见下方接口文档。
