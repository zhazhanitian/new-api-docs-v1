提交豆包 Seedance 视频生成任务（文生、首帧 / 首尾帧、全模态参考）。

请求地址仍为 `POST /v1/video/generations`，完成后用 `GET /v1/video/generations/{task_id}` 查询。

`prompt` 必填，推荐只用 `prompt` 传提示词。

**人像库（自 Seedance 2.0 起）：** 参考图、参考视频、首帧等素材中**包含人脸**时，须先完成 [人像库审核](/zh/docs/api/ai-model/videos/doubao/portrait)，待 `status` 为 `Active` 后，在 `metadata.content` 中传入 **`asset://{asset_id}`**（不要用原始 HTTPS，也不要用 `resolved_url`）；**否则人脸无法用于视频生成**。不含人脸的场景图可继续直接传公网 URL。适用于 2.0 及后续所有版本。

提示词里用「图片 1」「图片 2」指代 `content` 中的素材，不要把 `asset://...` 写进 `prompt`。

各版本能力与字段说明见下方接口文档。
