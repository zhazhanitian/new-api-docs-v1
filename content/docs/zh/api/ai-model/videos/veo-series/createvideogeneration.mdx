提交 Veo 视频生成任务（文生、首帧、首尾帧、参考图）。

请求地址仍为 `POST /v1/video/generations`，完成后用 `GET /v1/video/generations/{task_id}` 查询。

素材只通过 `metadata.content` 传入。首帧写 `role=first_frame`，尾帧必须和首帧一起传。参考图写 `reference_image`，并用 `reference_type` 标明 `asset` 或 `style`。不支持参考视频。

时长固定 8 秒。分辨率使用大写 `720P`、`1080P`，宽高比只支持 `16:9`、`9:16`。

各版本能力与字段说明见下方接口文档。
