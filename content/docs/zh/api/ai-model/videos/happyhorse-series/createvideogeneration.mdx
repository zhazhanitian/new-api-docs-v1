提交 HappyHorse 视频生成任务（文生、首帧、参考图、视频编辑）。

请求地址仍为 `POST /v1/video/generations`，完成后用 `GET /v1/video/generations/{task_id}` 查询。

图生、参考图、视频编辑的素材只通过 `metadata.content` 传入。首帧写 `role=first_frame`，参考图写 `reference_image`，待编辑视频写 `type=video_url`。

宽高比写 `ratio`，只用于文生和参考图。图生跟随首帧，视频编辑跟随输入视频，并且不传 `duration`。

各版本能力与字段说明见下方接口文档。
